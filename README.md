# Regalo

Web interactiva de regalo: túnel 3D por capítulos, collage de fotos con profundidad y paralaje de ratón.

- `npm run dev` — desarrollo en http://localhost:5173
- `npm run build` — build de producción (se publica sola en GitHub Pages al hacer push a `main`)

El contenido (textos, colores, fotos) se edita en `src/data/story.js`.
